TwIL-8B: a free reasoning AI model you can run on your own computer

By AiCoN | Published 9 November 2026 | Sources checked 9 November 2026

TwIL-8B is an open-weights AI model from the company webAI, built for math, coding and following instructions. You download it once and run it on your own computer, so chats stay on your device. The licence allows non-commercial use only.

Quick facts

  • What it is: an 8.79 billion parameter reasoning model. It writes out its thinking before it answers.
  • Who made it: webAI. It is post-trained from IBM's Granite 4.2 8B model.
  • Price: free to download. No account is needed on the model page.
  • Licence: webAI Non-Commercial License 1.0. The IBM base model is Apache 2.0, but webAI's licence applies to TwIL-8B. Read it before you use the model.
  • Context: 131,072 tokens. Language: English.
  • Runs on: Windows, Mac and Linux through llama.cpp or LM Studio.
  • Checked by AiCoN: we read the official model card and licence on 9 November 2026. We did not download or run the model.

What is new

The official repository shows a first upload on 14 October 2026. On 3 November 2026 webAI published the current setup with two variants, and a third-party write-up says the licence text changed on 4 November. So check the licence page on the day you download.

  • balanced (the default): shorter reasoning, lower cost per answer. Use this for normal work.
  • verbose: longer reasoning for hard contest-style problems.

Is it free to use?

It is free to download. The webAI Non-Commercial License allows non-commercial use. That fits learning, homework and personal projects. It does not fit client work, a paid product or anything you charge for. If you need a model for commercial work, choose one under Apache 2.0 or MIT, such as IBM's Granite 4.2 8B base model.

How good is it?

These scores are webAI's own, from its model card. AiCoN has not checked them, and rival scores come from different test setups.

  • Math: MATH-500 98.2 and AIME 2025 88.3. On AIME 2026 it scores 88.3, behind Qwen3.5-9B at 92.5.
  • Code: LiveCodeBench 81.6, measured on the verbose variant. The card puts it within 2.9 to 6.2 points of GPT-5.5, Claude Opus 4.8 and Grok 4.3 on that test.
  • Instructions: IFEval 91.8, level with Qwen3.5-9B at 91.5.
  • Weak spot: general knowledge. GPQA Diamond is 70.2, against 81.7 for Qwen3.5-9B and 84.3 for Gemma 4 31B.

In plain terms, it targets puzzle-style math and code help. For questions about facts, a larger online chatbot will do better. webAI also says there is no safety or preference tuning beyond what the Granite base carries, so do not rely on it for medical, legal or safety-critical answers.

What do you need to run it?

The model is a large file, and your memory decides which version fits. The official GGUF files are listed on the model card in GiB. The community builds come from a separate repository, liodon-ai/TwIL-8B-GGUF, whose page lists the sizes and rough memory figures below. AiCoN did not download any of them.

webAI says the Q4_K_M file is meant for CPU or graphics cards with modest memory. The full-precision Python route needs a lot more memory, around the size of the 16.38 GiB checkpoint plus working space. All scores on the card were measured on the full bf16 weights, so smaller downloads can score a little lower.

One practical warning from the card: this model thinks at length. On contest math it averages about 19.5k tokens per AIME 2026 problem. On a slow computer, hard questions can take a long time. Cutting the answer budget short makes results much worse.

How to run it

Option 1: LM Studio, no commands

We wrote about LM Studio in our LM Studio guide. Install it from lmstudio.ai/download, search for the model inside the app, download a GGUF file, then open a chat. We did not check whether LM Studio lists TwIL-8B in its search today, so if it does not appear, download the file from Hugging Face and add it to LM Studio's models folder.

Option 2: llama.cpp, official command

This command is from webAI's model card. It downloads the balanced Q4_K_M file on first use.

llama-cli -hf webAI-Official/TwIL-8B --hf-file TwIL-8B-Q4_K_M-balanced.gguf -cnv -c 40960 -n 32768

Name the file with --hf-file, because the same quant exists for both variants. Keep -c and -n large so the thinking is not cut off.

To download a variant for offline use:

# balanced (default)
hf download webAI-Official/TwIL-8B --exclude "verbose/*" --exclude "*.gguf" --local-dir TwIL-8B-balanced

# verbose
hf download webAI-Official/TwIL-8B --include "verbose/*" --local-dir TwIL-8B

Option 3: Python, for developers

Example from the model card. Use a Transformers release that supports Granite 4.2.

import torch
from transformers import AutoModelForCausalLM, AutoTokenizer

model_id = "webAI-Official/TwIL-8B"
variant = None  # balanced (default); use "verbose" for the verbose variant

tok = AutoTokenizer.from_pretrained(model_id, subfolder=variant or "")
model = AutoModelForCausalLM.from_pretrained(
    model_id, subfolder=variant or "", dtype=torch.bfloat16, device_map="auto"
)

messages = [{"role": "user", "content":
             "How many positive integers n < 1000 are divisible by 3 but not by 5? "
             "Reason step by step, then give the final integer."}]
inputs = tok.apply_chat_template(
    messages, add_generation_prompt=True,
    return_tensors="pt", return_dict=True,
).to(model.device)

out = model.generate(**inputs, max_new_tokens=32768)
print(tok.decode(out[0][inputs["input_ids"].shape[-1]:], skip_special_tokens=True))

What about Ollama?

We did not find a TwIL-8B entry in the official Ollama library. The community repository above shows this command for its Q4_K_M file:

ollama run hf.co/liodon-ai/TwIL-8B-GGUF:Q4_K_M

That is a third-party repository, not webAI's, and we did not run the command. Our Ollama guide covers the basics.

Limits

  • AiCoN did not run this model. Everything here comes from official pages and the community repository named above.
  • Benchmark numbers are webAI's own. Rows marked with a dagger on the card, including LiveCodeBench and IFBench, were measured on the verbose variant, not on balanced.
  • The licence is non-commercial only.
  • It is weak on general knowledge compared with large online chatbots.
  • It is a laptop or desktop model. We found no phone route for it.
