Reactive Resume: free open-source resume builder

By AiCoN | Published 17 October 2026 | Sources checked 17 October 2026

Reactive Resume is a free, open-source resume builder. Its README says there is no paid tier and no tracking, and optional AI features use a provider you connect.

What it is

Reactive Resume is a resume builder you use in your browser. Its homepage says: "Reactive Resume is a free, open-source resume builder. Write it, design it, check it, tailor it for every job." You type beside a live preview of the page, pick a template, and export a file. The GitHub README says it also does cover letters and has a job application tracker. It is not mainly an AI tool, though it has an optional AI assistant (see below).

Is it free?

Yes, per the project. The GitHub README says the code is open source under the MIT licence, "with no tracking, no ads, and no paid tier". The docs describe it as "free to use". There is one catch the README states: the optional AI features use a provider you connect, and "hosting and provider usage may have their own costs". That means if you connect an AI service, that service may charge you. The builder itself has no paid tier, per the README.

What you can do with it

  • Write and design. A live PDF preview, rich text, drag-and-drop ordering, autosave and 17 templates, per the README. It lists one-column, two-column and "ATS-safe" template filters.
  • Check your resume. The README lists readability checks, job-posting keyword matching and a view of the text hiring software reads. It also mentions a public ATS checker that reads PDFs in your browser without an account.
  • Import and export. Import from LinkedIn data exports, PDF and Word, and export PDF, Word, Markdown or JSON, per the README. It says Word import needs a connected AI provider.
  • Share a link. Public links can have a password, per the README.
  • Track job applications and write cover letters. Listed in the README.

What to watch out for

  • Account. The README says to create a free account. The docs introduction says you can create and export "without accounts or paywalls", which is not what the README and quickstart say. We could not settle this, so assume you need an account.
  • The AI assistant is optional and uses your own provider. The README says you connect OpenAI, Anthropic, Google Gemini or another provider. We did not try it.
  • Similar tools exist. This is another resume builder. We posted about Rezi earlier, which has a limited free plan. Reactive Resume says it has no paid tier.
  • Not tested. We did not make an account or build a resume.

Privacy and data

  • The README says "no tracking or ads", and that you can export your account data or delete your account. The docs have guides for both.
  • Your resume holds personal details such as phone and email. Remember a public share link can be opened by anyone who has it, and a password is optional.
  • You can run your own copy with Docker, per the README. Then the data is on your own server.
  • If you connect an AI provider, your resume text goes to that provider. Check its policy.

India

  • We found no region limit on the pages we read. No rupee price is involved. The README says it supports A4 and Letter paper, and A4 is the usual size in India.

Frequently asked questions

Is Reactive Resume free?

Yes, per its README: no paid tier. Optional AI providers you connect may charge you.

Can I make a cover letter?

Yes, the README lists standalone cover letters.

Can I delete my data?

The README says you can export your data or delete your account.
