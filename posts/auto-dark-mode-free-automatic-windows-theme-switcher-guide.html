Auto Dark Mode: free automatic dark and light theme for Windows

By AiCoN | Published 21 October 2026 | Sources checked 21 October 2026

Auto Dark Mode is a free, open-source app that switches Windows between dark and light theme at set times, like phones and Macs already do. Its privacy statement says it collects no data. Here is what its pages say.

Quick facts

  • What it does: automatically switches Windows between the dark and light theme on a schedule, or with sunrise and sunset. It can also change your wallpaper and run custom scripts on switch.
  • Price: free, including the Microsoft Store version (price 0 on its listing). Open source under GPL 3.0.
  • Platforms: Windows 10 and Windows 11, per its GitHub description.
  • Best for: anyone who wants a light screen by day and a dark one at night without changing settings by hand.

What it is

Auto Dark Mode brings automatic theme switching to Windows. Its Microsoft Store description puts it simply: "Tired of looking at dark content while the sun is shining brightly? But at night everything is suddenly too bright? Auto Dark Mode is the solution for you!" Android, iOS and macOS already change design with the time of day; this app does the same for Windows 10 and 11.

Is it free?

Yes. The GitHub repository is under the GNU GPL 3.0 licence, and the Microsoft Store listing shows a price of 0. We found no paid version on any channel.

What the pages list

  • Switches dark and light theme at scheduled times or from sunset to sunrise, per the store description.
  • Can change the desktop wallpaper and run custom scripts when the theme changes.
  • Latest release 11.1.1.1, published 16 August 2026 on GitHub.
  • Install from the Microsoft Store or GitHub.

Privacy and data

  • The project's privacy statement says: "We (the Auto Dark Mode Team) don't collect any data about our users. This app does not use telemetry, all settings are saved offline and log files are only stored on the personal computer."
  • Location for sunrise and sunset is processed on your PC only, per the statement; it can use the Windows location service, where Microsoft's own privacy policy applies.
  • Update checks talk to GitHub's servers, where GitHub's privacy policy applies, per the statement.

Our advice

  • Set it to "From sunset to sunrise" for the most natural switching. This is our advice, not the project's.
  • Some older apps ignore the Windows theme switch; that is a limitation of those apps, not of this tool.
  • Install from the Microsoft Store listing or the project's GitHub page only.

India

  • No region limit appears on the pages we read. We did not test it from India.

Frequently asked questions

Is Auto Dark Mode free?

Yes. It is open source under GPL 3.0, and the Microsoft Store version shows a price of 0.

Does it spy on me?

Its own privacy statement says it collects no data and uses no telemetry. Update checks connect to GitHub, and sun-time mode can use Windows location services.

Yes. Its description covers Windows 10 and Windows 11.
