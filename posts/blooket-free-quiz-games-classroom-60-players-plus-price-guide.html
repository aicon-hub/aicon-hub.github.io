Blooket: free quiz games for the classroom, up to 60 players

By AiCoN | Published 9 November 2026 | Sources checked 9 November 2026

Blooket is a website where teachers turn quiz questions into games for the class. The official help page says all essential features are free. You pay only if you want extras.

Quick facts

  • Free plan: the Blooket help page "Is Blooket Free?" says you can create an unlimited number of question sets and host a game with up to 60 people.
  • Plus plan: the same page says Plus members can host up to 300 people, except in Racing and team modes.
  • Plus price: the upgrade page shows $4.99 a month, charged yearly at $59.88 (about Rs 440 a month, Rs 5,270 for the year, at Rs 88 to the dollar).
  • Starter plan features listed on the upgrade page: create or discover sets, unique game modes, question set search and up to 60 players. Plus adds exclusive game modes.
  • Checked by AiCoN: we read the Blooket help page and upgrade page on 9 November 2026 through our search tool. Blooket blocked our direct page loads, so we did not see the site itself. We did not host a game.

Who is it for?

Teachers who want revision or review quizzes that feel like games. Students join a game that a teacher hosts.

How to start

  1. Open blooket.com and read how teachers sign up. We did not create an account.
  2. Create a question set, or search the sets other teachers made.
  3. Pick a game mode and host the game for your class.

Limits and things to know

  • AiCoN did not use Blooket, so we cannot say which game modes work best in a class.
  • 60 players per game on the free plan may be too few for a large class. Split the class or use Plus.
  • Prices are in US dollars on the official page. A card payment may add a foreign-exchange fee.
  • Check your school rules for student data and for children under 13 before you use any online game site.

Sources: Is Blooket Free? · Blooket upgrade page. Independent guide by AiCoN - not affiliated with Blooket. Checked 9 November 2026. Details can change; check the official source before you act.
