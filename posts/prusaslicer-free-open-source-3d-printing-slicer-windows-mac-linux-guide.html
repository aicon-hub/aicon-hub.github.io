PrusaSlicer: free open source software to prepare 3D models for printing

By AiCoN | Published 21 October 2026 | Sources checked 21 October 2026

Prusa says PrusaSlicer is "Free. Open-source. No account required. Runs on your machine." It turns a 3D model file into print instructions for a 3D printer.

Quick facts

  • What it does: takes a 3D model file and generates the print instructions (G-code) your 3D printer follows. This step is called slicing.
  • Price: free. The product page says "Free. Open-source. No account required." and "Free: All of it. The slicer, the profiles, the updates."
  • Platforms: Windows, macOS and Linux.
  • Best for: people who own or use a 3D printer. It does not design models and does not print anything without a printer.

What it is

PrusaSlicer is made by Prusa Research. Its README says it "enables you to take your 3D models, generate 3D printing instructions and send them to your 3D printer", and that it supports both FDM and mSLA printers. It says that apart from Prusa printers it supports machines from many other makers. The README says it is originally based on Slic3r.

Is it free?

Yes, per Prusa. The page says the slicer, the profiles and the updates are free, and funded by Prusa's hardware and filament sales. The GitHub project is under the AGPL-3.0 licence. No price appears on the pages we read, so there is nothing to convert to rupees. Prusa also sells an online course, the PrusaSlicer Masterclass. We did not check its price and the software does not need it.

What the page lists

  • Three modes in one app: Simple, Advanced and Expert.
  • Organic-shaped supports that touch the model only where needed, and painting of support zones.
  • Multi-material colour painting, including filament changes at set layers for single-extruder printers.
  • Cutting a big model into pieces with alignment pins, plus paint, arrange and 3D preview tools (README).
  • More than 200 tested profiles for Prusa printers and filament, updated through the built-in updater.
  • Sending print files to your printer over the local network, and a command-line interface (README).

Good to know, per Prusa

  • The product page lists version 2.9.6, released 25 June 2026, for Windows 10 or later. GitHub shows the same release.
  • A PrusaSlicer 3.0.0-alpha12 preview, released 21 September 2026, is offered separately. Prusa says it does not recommend pre-release builds for production.
  • The README says Linux builds come only through Flathub, and macOS and Windows can also be downloaded from GitHub releases.
  • Prusa also offers EasyPrint, a phone and tablet version that runs on its servers. It says EasyPrint is free. This article is about the desktop program.

Our advice

  • Choose your printer profile first. Wrong settings can waste filament or damage a print. We did not test any printer.
  • Use the stable version, not the 3.0 alpha preview.
  • Download only from prusa3d.com or the GitHub releases page the README links.

Privacy and data

  • Prusa says all slicing happens locally on your machine, and that your 3D models, profiles and G-code "never leave your computer unless you explicitly send them somewhere".
  • It says no account is required and that it works offline. Features that connect to online services, such as PrusaConnect and Printables, are optional per the README. We did not read their privacy terms.

India

  • No region limit appears on the pages we read for the software. We did not test it from India.

Source code

The GitHub project prusa3d/PrusaSlicer is under AGPL-3.0 and has about 9,400 stars, per its GitHub page.

Frequently asked questions

Is PrusaSlicer free?

Yes. Prusa's page says it is free and open source, with no account required.

Do I need a Prusa printer?

No. The README says it supports machines from a wide variety of makers.

Does it work offline?

Yes, per Prusa. It says all slicing happens on your machine.
