RapidFuzz: shortlist similar names without auto-merging

By AiCoN | Published 28 October 2026 | Sources checked 28 October 2026

A misspelled product name can be hard to find with an exact lookup. RapidFuzz ranks strings by similarity, so you can shortlist candidates for review. Our five-query test also shows why you should not merge records just because the score looks high: an unlisted 3m cable scored 94.44 against both 1m and 2m cables.

Quick facts

  • Purpose: fuzzy string matching in Python. Useful before a manual catalog or spreadsheet cleanup, not proof that two records are the same item.
  • Tested: RapidFuzz 3.14.5, Python 3.10.12/Linux; four fictional catalog entries, five queries, explicit ratio scorer and preprocessing.
  • Version scope: 3.14.5 supports Python 3.10. The current 3.14.6 package requires Python 3.11 or later; that release was not tested.
  • Cost and licence: the official code repository lists MIT. No account, API key, card, payment or hosted service used in this test.
  • Privacy scope: fictional names only. After installation, the script returned byte-identical output inside a process with networking disabled. This is not a security audit.
  • India: no India-specific availability claim established. This is a local code workflow.

Why use it beside a chatbot?

You can run the same explicit scorer over your own catalog and return ranked names with numeric scores, without asking a model to invent likely matches. A chatbot can help write the script; RapidFuzz performs the actual comparisons. It is string matching, not a language model, semantic search or a product-identity service. We did not benchmark speed or test a large catalog.

The trap this test catches

The catalog has two paper weights and two cable lengths. A capitalization variant ranked the intended paper first at 100.0. A spelling error, Papre instead of Paper, ranked it first at 95.83. But a query missing the cable length tied at 90.91, and an unlisted 3m cable tied at 94.44 against both listed lengths.

A cutoff of 80 did not protect against those wrong-product candidates. The script therefore keeps two results and flags a gap below five points for review. Both 80 and five are demonstration choices, not validated thresholds. Even a clear top result still requires a check of exact product attributes.

Exact tested code

import rapidfuzz
from rapidfuzz import fuzz, process, utils

catalog = [
    'Northstar Paper A4 80gsm',
    'Northstar Paper A4 100gsm',
    'Orbit USB Cable 1m',
    'Orbit USB Cable 2m',
]
queries = [
    'northstar paper a4 80GSM',
    'Northstar Papre A4 80gsm',
    'Orbit USB Cable',
    'Orbit USB Cable 3m',
    'Banana',
]
print('RapidFuzz', rapidfuzz.__version__)
print('scorer=ratio | processor=default_process | cutoff=80')
for query in queries:
    matches = process.extract(
        query, catalog, scorer=fuzz.ratio,
        processor=utils.default_process, score_cutoff=80, limit=2,
    )
    print('\nquery:', query)
    print('candidates:', [(name, round(score, 2)) for name, score, _ in matches])
    if not matches:
        print('review: no candidate above cutoff')
    elif len(matches) > 1 and matches[0][1] - matches[1][1] < 5:
        print('review: close scores; check exact product attributes')
    else:
        print('review: check top candidate; do not auto-merge')

Run the pinned route

In an isolated Python 3.10 environment, install the version we tested, save the code as demo.py and run it:

pip install "rapidfuzz==3.14.5"
python demo.py

The process API describes extract and its cutoff and result-limit controls. We explicitly set scorer=fuzz.ratio, processor=utils.default_process, score_cutoff=80 and limit=2 rather than relying on defaults.

Read the scores correctly

  • ratio measures normalized Indel similarity from 0 to 100. A score of 94.44 is not a 94.44% probability of identity.
  • default_process removes non-alphanumeric characters, trims whitespace and lowercases text. Inspect whether that destroys meaning in your identifiers before using it.
  • Preserve original values. Check SKU, size, unit, model number and other structured fields separately. Do not overwrite or merge source records with this demo.
  • A score gap is only a warning heuristic. A wide gap can still select the wrong item when the correct one is absent.
  • We tested English product strings only. No Malayalam, multilingual matching, real customer records, accuracy rate, throughput or large-file workflow was evaluated.
