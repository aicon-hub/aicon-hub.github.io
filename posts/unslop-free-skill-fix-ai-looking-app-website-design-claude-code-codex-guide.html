unslop: a free skill that fixes AI-looking app and website design

By AiCoN | Published 9 November 2026 | Sources checked 9 November 2026

unslop is a free skill for AI coding agents. You point it at a screen that looks AI-generated, and it lists what gives it away, picks a design direction, then fixes the screen layer by layer. It is a design tool, not a text editor.

Quick facts

  • What it is: a skill (a folder of instructions and scripts) for Claude Code, Codex and Google Antigravity.
  • Who made it: Damir Sokolovsky (@heydamir). The repository is github.com/heydamir/unslop.
  • Licence: CC BY 4.0. You can use, change and share it, including commercially, if you credit Damir Sokolovsky and link to the repository.
  • Price: free. You still need one of the supported coding agents, and we did not check what plan those need.
  • Age: the repository was created on 29 October 2026. It had about 12,000 GitHub stars when we looked on 9 November 2026.
  • Checked by AiCoN: we read the README and the skill file on 9 November 2026. We did not install or run it.

What problem does it fix?

Screens made quickly with AI tools tend to look alike: purple gradients, glowing cards, emoji labels, "New" badges, shouting copy and uneven spacing. The README calls this vibecoded slop. unslop keeps the product, its features and its content, and changes how it looks and reads.

How does it work?

  1. It looks at the screen, from your code, a screenshot or a live site link.
  2. It audits the screen and lists every sign of slop and where it lives.
  3. It writes a short direction (product, character, world, moments, signature) and shows it to you before it edits anything, unless you tell it to just go ahead.
  4. It fixes the screen in nine passes, in order: spacing, color, icons, copy, type, layout, details, visuals and motion.
  5. It checks the result against the audit and reports what changed.

If the screen is already well designed, the README says it tells you so and suggests a few small refinements instead of redesigning it.

What does it need?

  • One of the three agents above.
  • For a live site, or for the optional story video, Playwright with its Chromium browser. The video also needs ffmpeg.
  • Optional: an image service such as fal, Replicate, OpenAI images or Higgsfield for a hero picture. The README says it shows the prompt and asks before each paid generation. Dashboards and apps rarely need one.

How to install it

These commands are from the README. Run them only if you are comfortable copying a skill from a public repository, and read the files first.

Claude Code

git clone https://github.com/heydamir/unslop
mkdir -p ~/.claude/skills && cp -r unslop/skills/unslop ~/.claude/skills/

To use it in one project only, copy it into .claude/skills/ inside that project.

Codex

$skill-installer install https://github.com/heydamir/unslop/tree/main/skills/unslop

Or copy it by hand into ~/.agents/skills/.

Google Antigravity

git clone https://github.com/heydamir/unslop
mkdir -p ~/.gemini/antigravity/skills && cp -r unslop/skills/unslop ~/.gemini/antigravity/skills/

For live sites and the video

npm install -D playwright
npx playwright install chromium

How to use it

In Claude Code type /unslop and what you want. In Codex type $unslop. Or describe the task in your own words. The README gives these examples:

/unslop this dashboard
/unslop the hero of https://example.com
/unslop my landing page and make the story video so I can post it

Limits and things to know

  • AiCoN did not install or run unslop. We cannot say how good its results are. The before and after picture in the README is the author's own.
  • It changes code in your project, so use version control and review the changes.
  • It is about how a screen looks. It does not check that your app works, is accessible or is accurate.
  • The author also sells a service where he redesigns one key screen in 3 days (heydamir.design/unslop). The skill itself is free.
  • The repository is new. Its instructions can change, so read the README on the day you install.
