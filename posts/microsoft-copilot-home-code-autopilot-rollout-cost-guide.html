New Copilot: Home, Code, Autopilot and rollout costs

By AiCoN | Published 7 October 2026 | Sources checked 7 October 2026

Microsoft announced a new Copilot experience on 25 September 2026 with Home, Code and Autopilot. The announcement mixes current services, staged Frontier access and private previews. A Microsoft 365 subscription alone does not prove that your account has every new feature or that long-running agent work is covered at a fixed cost.

Home, Chat and Cowork

Home is described as the starting point where Chat and Cowork meet. Chat handles quick conversational work; Cowork is described as handling delegated tasks such as a launch kit or briefing.

Microsoft says automatic routing between modes is coming soon. Do not treat that future routing as already active for every account.

Office inside Copilot

The announcement describes creating and editing real Word documents, Excel workbooks and PowerPoint presentations inside Copilot, with collaborative updates across the apps.

An editable file still needs inspection. Check formulas, sources, formatting and audience before using it in a decision or sharing it with colleagues.

What Code adds

Code is described as building apps, dashboards, trackers and automation from natural-language requests using technology related to GitHub Copilot.

Microsoft describes a sandbox and tenant hosting. That is not a blanket approval for a generated application to access production data or be shared with everyone.

Code access is staged

The September announcement says Code starts in Frontier and expands in the following weeks. It says Microsoft 365 Premium and Pro subscriber preview is planned later in the year.

A planned expansion is not a confirmed entitlement in your tenant. Ask the administrator and inspect the actual feature before promising a workflow built around it.

Autopilot and the old Scout name

Microsoft says Autopilot was previously called Scout. It describes a persistent cloud agent with its own identity, memory, computer and workspace inside the tenant.

It can be given a role and goal and is described as watching channels, handling recurring work and following up. The announcement says private preview is expanding, not that every personal account can use it.

Permissions and representation

An identity in a company directory can support access controls and audit, but it does not decide what a person authorised the agent to say or do.

Define allowed sources, recipients, actions and approval steps. Review communications, schedule changes and sensitive writes before enabling an unattended process.

Managed Runtime is also preview

The announcement calls Copilot Managed Runtime hosting infrastructure for code inside the organisation's Microsoft 365 environment. It says this runtime is in preview.

Check actual hosting limits, identity mapping, data access and operations support. Generated code and a hosted runtime are different parts of a safe deployment.

Subscriptions versus usage billing

Microsoft distinguishes a user subscription licence for everyday Copilot work from usage-based billing for Cowork, Code, Autopilot and other long-running capabilities or frontier models.

No complete per-task rate or final tax-inclusive India bill was established here. Confirm subscription, credit allocation, model selection, runtime charges and spending controls together.

FinOps controls

The announcement describes spending policies, model-family controls, credit requests and visibility into usage and remaining balances. Some capabilities have staged or planned expansion.

A dashboard showing cost is not the same as a tested hard limit. Check what happens when a budget is exhausted and who can approve more spend.

A safe organisation trial

  1. Confirm account, tenant and preview access.
  2. Choose a small task with approved sample information.
  3. List the permitted tools, recipients and output audience.
  4. Set administrator spending and model controls.
  5. Require review of external messages and sensitive changes.
  6. Check generated files or code directly.
  7. Inspect audit records and actual credit usage.
  8. Test a denied action and a budget boundary.
  9. Expand only after the trial meets your requirements.

No subscription, preview application, agent identity or tenant setting was changed for this guide.

India and future features

The global announcement does not establish every Indian account's rollout, local data processing or Malayalam quality. Personal and commercial licences can have different access.

Today in Home is described as entering private preview in October, with Outlook and Teams expansion later. The shared-context @Copilot experience is also described as private preview. Preserve those limits.

What changed since the original post?

We separate the planned modes, preview runtime and account-specific access. Autopilot's old name is preserved, and usage billing is not hidden behind the subscription wording.

Frequently asked questions

Does my subscription include everything?

Not established. Access and usage billing need checking.

Is Autopilot public for all users?

The announcement describes private preview.

Was a tenant tested?

No.
