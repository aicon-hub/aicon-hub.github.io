PDF24 Tools: free PDF tools online, and an offline Windows version

By AiCoN | Published 20 October 2026 | Sources checked 20 October 2026

PDF24 says all its PDF tools are free of charge and without restrictions, paid for by some advertising on its web pages.

What it is

PDF24 Tools is a set of PDF tools from geek software GmbH. Its home page lists tools such as Merge PDF, Split PDF, Compress PDF, Edit PDF, Sign PDF, Protect PDF, Unlock PDF, Rotate PDF pages and Extract PDF pages. They run in your web browser. For offline use there is PDF24 Creator, a Windows program. It is not an AI tool.

Is it free?

Yes, per PDF24. Its home page says "You can use all PDF24 tools free of charge and without any restrictions. This is achieved via some advertising on the web pages." The Creator download page calls it "Free Windows software for private and business use" and says it works offline "so files stay on your PC".

Online or offline, per PDF24

  • Online tools: "No installation necessary". They work in the browser, and the site says Windows, Linux, Mac and phones are supported. Files are processed on PDF24 servers.
  • PDF24 Creator: installs on Windows, gives all PDF24 tools offline and includes a PDF printer. The page lists version 11.31.1 as the latest when we read it.

Our advice

  • For a bank statement, ID scan or any private paper, use the offline Creator so the file stays on your PC.
  • Expect ads on the website, as PDF24 says. Download the Creator only from creator.pdf24.org.

Privacy and data

  • PDF24 says: "File transfers to the PDF24 servers are encrypted. All files are completely removed from our servers after a short time." It does not say how long that is on the page we read.
  • It says that in the Creator "all files remain on your PC".
  • Its privacy policy says the website stores server log files such as browser type and operating system, and uses cookies. The company is geek software GmbH. We did not read every section.

India

  • No region limit appears on the pages we read. We did not test it from India. There is no price to convert.

Frequently asked questions

Is PDF24 free?

PDF24 says its tools are free of charge and without restrictions, paid for by advertising.

Does it need an installation?

Not for the online tools. The offline Creator is a Windows program.

Are my files uploaded?

With the online tools, yes, to PDF24 servers, which it says are encrypted and cleared after a short time. The Creator keeps files on your PC, per PDF24.
