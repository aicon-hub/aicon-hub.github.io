Tesseract by Mirage: editable video and current platform limits

By AiCoN | Published 7 October 2026 | Sources checked 7 October 2026

Tesseract by Mirage gives compatible agents tools for video editing, motion graphics, designs and audio. The current official pages include macOS, Windows and Linux, plus supported hosted environments. This changes the archive's older Mac/Windows and browser-only limitation.

What does it create?

Tesseract works with an editable project of layers, compositions, timing, keyframes and sound. You can refine a title, clip, effect or audio balance without asking for a whole new flattened video.

The official page describes editing existing media and making motion graphics. Generating new footage or avatars is a separate job. Bring recordings, images and audio you are allowed to use.

Current device and agent support

The repository lists macOS, Windows and Linux x86_64, including compatible cloud-agent environments. Its downloads include Apple Silicon and Intel Mac builds, Windows and Linux CLI builds, and a separate web runtime.

The official site says ChatGPT Mobile can use a hosted environment. A chat screen without the needed environment, file access and tools is not enough. Avoid the old blanket claim that no browser or hosted chat can ever use it.

Plugin versus skills

The current repository lists a ChatGPT/Codex plugin and says the Claude Code plugin is coming soon. It also provides a skills route for supported agents.

These are different installation routes. The docs say to use either the plugin or skills, not both, and to use the CLI version required by the skills. Do not call a coming-soon plugin already released.

What is free?

The official website says the local creative engine, preview and rendering are free. Agent subscriptions or model usage costs are separate. Local use does not require a Mirage account.

Captions is a separate app and cloud workspace. Free Tesseract engine access is not a free Captions subscription, free AI models or free cloud compute. No final Indian agent subscription or checkout price was verified.

Adobe transfer is not perfect compatibility

The site describes importing and exporting editable Premiere Pro or After Effects projects. It explicitly labels support partial and After Effects export experimental.

Keep the original project and compare the exported result. Unsupported effects, fonts, timing or assets can change. Do not promise that every Adobe project round-trips unchanged.

A careful creative workflow

  1. Check the exact platform and agent requirements.
  2. Read the official release and matching checksum instructions.
  3. Keep a copy of your original footage and project.
  4. Start with a small, harmless test clip.
  5. Supply your approved fonts, images, music and brief.
  6. Ask for an editable project, not only a final video.
  7. Preview representative frames and motion.
  8. Check captions, sound, crop, timing and spelling.
  9. Review imported or exported Adobe work separately.
  10. Save source assets alongside the final render.

Resolution is not restoration

The official page describes output settings including 4K and 60 FPS. A high-resolution output setting does not add missing detail to low-resolution footage or create genuine captured motion from a low-frame-rate source.

Watch a short render before processing a long video. Text safe areas, music rights, colour and audio clipping still need human review.

Privacy and India limits

Local rendering can keep media on your device, but a connected model or hosted agent may process it elsewhere. Read that service's upload, retention and access rules before supplying client or family footage.

No engine was installed, checksum verified or video rendered for this guide. Malayalam typography, Indian hardware performance and a particular hosted account were not tested.

What changed since the original post?

Repeated Tesseract posts become one guide. We add Linux and supported hosted agents, distinguish plugin availability and include partial Adobe transfer and separate agent costs.

Frequently asked questions

Does the free engine include my AI subscription?

No. Those costs are separate.

Can it use hosted agents?

Current official pages say yes for supported environments with the required access.

Does Adobe export preserve everything?

No. Support is partial; After Effects export is experimental.
