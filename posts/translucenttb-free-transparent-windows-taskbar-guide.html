TranslucentTB: free transparent taskbar for Windows

By AiCoN | Published 21 October 2026 | Sources checked 21 October 2026

TranslucentTB is a tiny free utility that changes how the Windows taskbar looks: fully clear, blurred, tinted or acrylic. It is free on the Microsoft Store and open source. Here is what its pages say.

Quick facts

  • What it does: makes the Windows taskbar transparent, blurred, opaque or acrylic, with a color picker and live preview.
  • Price: free, including the Microsoft Store version (price 0 on its listing). Open source under GPL 3.0.
  • Platforms: Windows 10 and Windows 11, per its Microsoft Store description.
  • Best for: anyone who wants a cleaner desktop without changing anything else.

What it is

TranslucentTB describes itself as "a lightweight (uses a few MB of RAM and almost no CPU) utility that makes the Windows taskbar translucent/transparent". Per its store listing, it runs in the background and changes how the taskbar looks. It was runner-up for the Microsoft Store App Awards 2022 Community Choice Award, per its store listing.

Is it free?

Yes. The GitHub repository is under the GNU GPL 3.0 licence, and the Microsoft Store listing shows a price of 0. We found no paid version on any channel. The project accepts voluntary donations via Liberapay, per its GitHub page.

What the pages list

  • Taskbar states: Normal, Opaque, Clear, Blur and Acrylic, each with its own color setting, per the project's README.
  • An advanced color picker with alpha support and live preview.
  • Dynamic modes that change the taskbar based on what is on screen, such as when a window is visible.
  • Latest release 2026.2, published 31 August 2026 on GitHub.

Privacy and data

  • We found no privacy statement on the project's pages. The code is open source, so anyone can inspect it, but we have not audited it ourselves and cannot confirm whether it collects or sends any data.
  • Installing through the Microsoft Store is covered by Microsoft's own store policies.

Our advice

  • Try the "Clear" state first for a fully transparent taskbar, then "Acrylic" if you want a frosted look. This is our advice, not the project's.
  • Install from the Microsoft Store listing or the project's GitHub page only.

India

  • No region limit appears on the pages we read. We did not test it from India.

Frequently asked questions

Is TranslucentTB free?

Yes. It is open source under GPL 3.0 and the Microsoft Store version shows a price of 0.

Does it slow down the PC?

Its own description says it uses a few MB of RAM and almost no CPU. We did not measure this ourselves.

Does it work on Windows 11?

Yes. Its store description covers Windows 10 and Windows 11; the Blur option needs specific Windows builds, per the README.
