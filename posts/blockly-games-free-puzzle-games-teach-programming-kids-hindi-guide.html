Blockly Games: puzzle games that teach programming, with Hindi in its language menu

By AiCoN | Published 19 October 2026 | Sources checked 19 October 2026

Blockly Games teach programming with block puzzles. Its pages say the code is free and open source, and it is made for beginners.

What it is

Blockly Games is a set of puzzle games that teach programming. Its About page says it "is designed for children who have not had prior experience with computer programming" and that "by the end of these games, one is ready to use conventional text-based languages". You snap blocks together instead of typing code. It was made by Google, per the GitHub page. It is not an AI tool, and it runs in a web browser.

Is it free?

The GitHub README says "All code is free and open source", under the Apache License 2.0, and the About page says the open source code "is free and customizable". We saw no price and no sign-in step on the pages we could read. No page says in so many words that playing is free, so we say only that.

The eight games, per the About page

  • Puzzle: a quick introduction to how the blocks snap together.
  • Maze: loops and conditionals, getting harder every level.
  • Bird: a deep dive into conditionals.
  • Turtle: loops, using nested loops to paint a picture.
  • Movie: mathematical equations, used to animate a movie.
  • Music: functions, used to compose music.
  • Pond Tutor: text-based programming. Levels switch between blocks and actual JavaScript in a text editor.
  • Pond: an open-ended contest to program the smartest duck, with blocks or JavaScript.

Good to know, per Blockly Games

  • It is "self-paced". The About page says it can be downloaded for offline use. We did not check how.
  • The front page has a "Clear data" option under "Want to start over?".
  • The language menu lists many languages. It includes Hindi, Bengali, Kannada and Urdu. We did not check how complete each translation is.

Our advice

  • It suits beginners and children, as the About page says. Start with Puzzle, then Maze.
  • Pond Tutor is where blocks turn into real JavaScript, so it is the natural next step.

Privacy and data

  • We read no privacy statement on the Blockly Games pages and make no claim on what data it collects. The "Clear data" option suggests progress is stored, but we did not check where. If a child uses it, check Google's privacy information first.

India

  • No region limit appears on the pages we read. We did not test it from India, and there is no price to convert.
