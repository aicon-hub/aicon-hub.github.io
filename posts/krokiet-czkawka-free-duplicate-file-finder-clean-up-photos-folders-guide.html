Krokiet (Czkawka): free tool to find duplicate files and clutter

By AiCoN | Published 19 October 2026 | Sources checked 19 October 2026

Krokiet scans your folders for duplicate files, similar photos and other clutter. Its README says it is free and open source, with no ads and no internet access.

Official Krokiet media

What it is

Krokiet is the main screen (the graphical front end) for Czkawka, a tool that scans your folders for clutter: duplicate files, empty folders, big files, temporary files, similar photos and more. The project's README calls Krokiet a "new generation GUI frontend, simple, multiplatform, fast and free app to remove unnecessary files from your computer". It is not an AI tool.

Is it free?

Yes, per the project. The README says "Free, Open Source without any ads" and calls Krokiet a "free app". We saw no price, account or sign-up. GitHub's license detector showed no single license for the whole repository. The repository lists an MIT license file for most of the code and a separate license file for icons. We did not read which license applies to each program, so we state no single license.

What it does, per the README

  • Duplicates: finds duplicates by file name, size or hash.
  • Similar images: finds photos that are "not exactly the same" (for example a different size or a watermark).
  • Others: empty folders, empty files, big files, temporary files, similar videos, similar music, broken files, wrongly named file types, and an Exif remover that strips photo metadata.
  • The README says second and later scans "should be much faster" because of caching.
  • It runs on Linux, Windows, macOS, FreeBSD and Android (the Android front end is called Cedinia).

How to get it

  1. Go to the project's GitHub releases page. The latest release we saw was 12.0.2, published 9 September 2026.
  2. The Krokiet README says prebuilt binaries are available for Windows 10 and 11, Mac and Ubuntu, with no required extras. The Windows list has several Krokiet files with different graphics options. The README says the releases page has recommendations on which to choose.
  3. The similar videos tool needs ffmpeg installed, per the README. Some photo formats (HEIF, RAW) are not in the prebuilt Windows files.
  4. The older Czkawka screen (GTK) is "superseded by Krokiet", and the README says version 12.0 is the last release with its binaries.

What to watch out for

  • It can delete files. The README lists tools to find files. We did not read how deletion or the recycle bin works. Our advice: back up first, and review every match before you delete. Similar images are guesses, not proof they are the same.
  • No installer or store listing was shown. You download a file from GitHub. We did not test it, so we cannot say how it looks or runs.
  • Pick the right file. The release page lists many files. Our advice: follow the project's own recommendations.

Privacy and data

  • The README says: "No spying - Czkawka does not have access to the Internet, nor does it collect any user information or statistics". That is the project's statement. We did not test it.
  • It scans folders you choose and keeps a cache for faster later scans, per the README.

India

  • We saw no region limit. We did not test downloads from India. We quote no INR price.

Frequently asked questions

Is Krokiet free?

The README says free, open source and without ads.

What is the difference between Krokiet and Czkawka?

Krokiet is the new screen. Czkawka is the project and its older screen.

Is there an Android version?

The README lists Cedinia, an Android front end. We did not check it further.
