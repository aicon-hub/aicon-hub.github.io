Squoosh: shrink images in your browser, nothing uploaded

By AiCoN | Published 17 October 2026 | Sources checked 17 October 2026

Squoosh is an open-source image compressor that runs in your browser. Its home page says images never leave your device. No official page calls it free, and we saw no price.

What it is

Squoosh is an image compression web app from Google Chrome Labs. Its GitHub page says it makes "images smaller using best-in-class codecs, right in the browser". Its home page says you open an image, compare the original and the smaller version, then save. It is not an AI tool. We included it as a handy way to shrink photos before emailing or uploading them.

Is it free?

No official page we read uses the word "free" for Squoosh. What we can say: the code is open source under the Apache License 2.0 (GitHub), and we saw no price, plan, sign-in or paywall on squoosh.app. Treat it as no-cost based on that, not as a stated promise.

What you can do with it

  • Shrink images. The home page says smaller images mean faster load times and that Squoosh can reduce file size while keeping high quality.
  • Compare. It shows the original and the result so you can inspect the difference before saving, per the home page.
  • Tune settings. The home page says you can adjust the settings for even smaller files.
  • Try it first. The home page offers demo images, including a large photo, so you can see how it works.

What to watch out for

  • One image at a time. We did not see batch compression described on its pages.
  • Settings can confuse. It offers many codecs and options. The simple path is to open, compare and save.
  • Not tested. We did not compress an image ourselves.

Privacy and data

  • The home page says "Images never leave your device since Squoosh does all the work locally". The README says Squoosh does not send your image to a server.
  • The README says Squoosh uses Google Analytics to collect basic visitor data and the before and after image size value.
  • For the installed web app (PWA), it says it also collects the type of installation and the install time and date.

India

  • It is a web app and we saw no price, so no rupee conversion is needed. We did not find any country limits. We did not test it from India.

Frequently asked questions

Does Squoosh upload my images?

The home page says no. Images stay on your device.

Do I need an account?

We saw no sign-in on the home page. We did not use the app.

Is it open source?

Yes. GitHub lists the Apache License 2.0.
