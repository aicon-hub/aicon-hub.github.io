Stretchly: a free break reminder app for Windows, Mac and Linux

By AiCoN | Published 18 October 2026 | Sources checked 18 October 2026

Stretchly is a small app that reminds you to take breaks while you work. Its README says it is free, with optional support through GitHub or Patreon.

What it is

Stretchly is a small app that reminds you to take breaks while you work on a computer. The project describes it as "a cross-platform Electron app that reminds you to take breaks when working on your computer" and calls it "the break time reminder app". It sits in your system tray and shows a reminder window now and then, with an idea for a break. It is not an AI tool. We make no health claims for it, because the project makes none on the pages we read.

Is it free?

Yes. The project's README says: "Stretchly is free but you can support it by contributing code, translations or money." The repository licence listed on GitHub is BSD-2-Clause. Supporters who sponsor on GitHub or Patreon get access to extra features such as Contributor Preferences and Sync Preferences, per the README. The basic app is free and does not need a sponsorship.

How it works by default

  • A 20 second mini break every 10 minutes, and a 5 minute long break every 30 minutes, per the README.
  • You get a notice 10 seconds before a mini break and 30 seconds before a long break.
  • You can postpone a break once, for 2 minutes or 5 minutes, and later skip it.
  • It pauses breaks when you have been idle for 5 minutes, and when Do Not Disturb is on.
  • It follows your system theme and has a dark mode. Most settings are in the Preferences window, and you can restore the defaults.

How to get it

  1. Open the project's downloads page or its GitHub releases page for installers for Windows, macOS and Linux.
  2. On Windows the README also lists Chocolatey, winget and the Microsoft Store. On macOS it recommends a Homebrew tap and says it needs macOS 13 (Ventura) or later.
  3. The latest release we saw on GitHub was v1.22.1.

What to watch out for

  • macOS warning. The README says the app is only ad-hoc signed, so macOS may block it on first launch. It lists steps to open it anyway. Only use the official downloads.
  • Windows Store version. The README says autostart does not work in that build and gives a workaround with the regular installer.
  • Linux on Wayland. The README lists known problems on some Wayland setups, with a workaround.
  • You can skip breaks. It is a nudge, not a lock. We did not test how it feels to use.

Privacy and data

  • We found no privacy statement on the README, site or downloads pages we read, so we cannot say what data the app sends, if any.
  • The project says features for supporters need you to sign in with GitHub or Patreon inside the app. You do not need to do that to use the basic app, per the README.

India

  • We saw no region limit and no price. We did not test downloads from India.
