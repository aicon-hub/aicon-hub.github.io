Elephant-Goldfish Model (EGM): the free Google plugin that makes AI coding agents design first

By AiCoN | Published 31 October 2026 | Sources checked 31 October 2026

EGM is an open source plugin, released by Google engineers in the last two weeks, for AI coding agents. Instead of letting the agent start writing code, it makes you write and test a design document first. We read the official site, the GitHub project and Google's announcement on 31 October 2026. We did not install or run it, so how well it works is not tested by AiCoN.

The idea in one line

"Design with an elephant. Review with a goldfish." That is the project's own tagline. The Elephant is a long, context-rich AI session that knows your project and drafts the specification. The Goldfish is a fresh AI session with no memory of that conversation, so it reads only the document and the code and points out gaps the Elephant cannot see. You decide the trade-offs and approve the design before anything is built.

What it is, who made it, and what it costs

  • What: a plugin made of skills (slash commands) and reviewer personas that run inside your coding agent.
  • Who: it is in the github.com/google organisation, and Google's Open Source Blog introduced it on 22 October 2026 (authors Brian Suchy and Dave Rensin). Google says thousands of its engineers use it daily. The README also says: "This is not an officially supported Google product."
  • Price: free. The code is under the Apache 2.0 licence, so you can use and change it. The plugin runs inside a coding agent such as Antigravity, Claude Code or Codex, and those tools and their AI models have their own plans and limits. We did not check what they cost.
  • When: the first public commit is dated 21 October 2026. The only release we saw was EGM v0.1.0, so it is early.

The workflow

  1. Brainstorm (/egm-brainstorm): talk the idea through with the agent. Fresh reviewers challenge it, and the agreed direction is saved as a concept brief.
  2. Draft (/egm-draft): the agent turns the brief into a design document, pausing after each section for your feedback.
  3. Review (/egm-review): fresh Goldfish reviewers check the design. Google's announcement describes three steps: a comprehension check (a Goldfish must explain the plan back), an antagonistic review by several sceptical Goldfish, and an implementation readiness check (are file paths, data structures and functions all spelled out).
  4. You approve the design, then ask your coding agent to build it.

The README lists seven skills you can use on their own: Brainstorm, Draft, Resolve (work through review findings), Bootstrap (write documentation for an existing codebase), Review, Review loop, and Drift report (compare the design documents with the current code). The README says to use it when a feature needs design decisions, and to use your normal workflow for a small, clear bug fix.

Which coding tools it works with

  • Antigravity, Claude Code and Codex: the project says these three pass its automated installation, reviewer isolation and end-to-end workflow tests. The install commands from the README, as listed: agy plugin install https://github.com/google/elephant-goldfish-model for Antigravity; claude plugin marketplace add google/elephant-goldfish-model then claude plugin install egm@egm for Claude Code; codex plugin marketplace add google/elephant-goldfish-model then codex plugin add egm@egm for Codex. Start a new session afterwards.
  • Others: its docs list working install paths for Claude Cowork, ChatGPT Work and omp, with open verification gaps for Cowork and ChatGPT Work. Standalone Antigravity IDE is listed as not supported.
  • The catch: the review steps need a tool that can start fresh sub-agents. If yours cannot, EGM stops the review rather than run it in the same session.

The limits, in its own words

  • "A review does not replace tests or human judgment."
  • It is aimed at design-heavy work. For small fixes the project says to skip it.
  • Install the whole plugin. Copying only the skills folder breaks it, per the docs.

Frequently asked questions

Is EGM free?

The plugin is free and open source under Apache 2.0. The coding agent you run it in has its own pricing, which we did not check.

Is it an official Google product?

It is published by Google engineers under github.com/google, but the README says it is not an officially supported Google product.

Do I need Antigravity?

No. The project lists Antigravity, Claude Code and Codex as tested, and other tools with working install paths.

Does it write the code?

Its job is the design: brainstorm, draft and review a specification. You then ask your coding agent to implement the approved design.
