Ollama: run a small AI model on your own computer

By AiCoN | Published 27 October 2026 | Sources checked 27 October 2026

Ollama is a program that downloads open AI models and runs them on your own computer, with a command line and a local web address other apps can use. You type a question and a model on your machine answers it. On 27 October 2026 we installed the Linux build on a small machine with no graphics card, downloaded a 0.4 GB model, and asked it to summarise a short made-up notice. It answered in about four seconds, also with the network switched off. The small model's answers varied, and one of them left out a detail, so treat small models as a drafting aid and check the result.

Quick facts

  • What it is: an open-source tool for running AI models locally. The GitHub repository lists the MIT License and has download instructions for macOS, Windows and Linux.
  • Models have their own licences: the model we used, qwen2.5:0.5b, is listed on its Ollama page under Apache 2.0 (the page says the 3B and 72B sizes use the Qwen licence instead). Check the page of any other model you pull.
  • Privacy: Ollama's FAQ says it runs locally and that the company does not see your prompts or data when you run locally. It also offers cloud-hosted models and web search, which work differently; the FAQ says they can be turned off with a setting. We did not use any cloud features or an account.
  • Cost: the software is free to download and no payment or card was involved in our test. Ollama's cloud features and any plans were not checked.
  • Download size: the model we used is 398 MB per its Ollama page. The Linux package we unpacked for the test was about 1.5 GB to download, including graphics-card libraries we did not use.
  • India: we did not find an India-specific availability statement in the sources we read, and did not check further.

Why use it

If you want to try an AI model on text that you would rather not paste into a website, such as your own notes, a draft or a school notice, Ollama lets the model run on your computer. It also lets you try different open models and call them from your own scripts. The trade-off is quality and speed: the model is limited by your computer, and a very small model gives rougher answers than the large online assistants.

What we tested

We used a Linux machine with about 2 GB of memory, 2 CPU cores and no GPU, running Ollama 0.40.11 and the qwen2.5:0.5b model (about 494 million parameters). The model download took about seven seconds on our connection. The notice we summarised is made up.

The commands we ran

# 1. Start the server and download a small model (needs internet once)
ollama serve
ollama pull qwen2.5:0.5b

# 2. Ask it something
ollama run qwen2.5:0.5b "Summarise in one sentence: The village library will close on 3 November for maintenance. Members should return all books before that date to avoid fines. The library will reopen on 10 November with extended evening hours."

The answers we got

Run 1 (online machine, right after the download):
The village library will close on November 3 for maintenance and reopen on November 10 with extended evening hours.

Run 2 (same model and prompt, network switched off):
The village library is scheduled to close on November 3rd for maintenance and members will be required to return their books before the date.

Reading the results: the first answer matches the notice. The second, produced with the network switched off, is shorter and leaves out the reopening date, which was in the notice. The two runs used the same prompt and model, so small-model answers can differ between runs. That second run took about four seconds in total. We ran each prompt once or twice, so this shows that the offline run works, not how good the model is.

Limits of our test

  • One tiny model and one short English prompt. We did not test larger models, Hindi or Malayalam, long documents, speed with a graphics card, the Windows or Mac apps, or the desktop chat window.
  • Offline here means the network was switched off after the model was downloaded. Installing and pulling a model needs internet.
  • We did not test the cloud features, so we make no claim about them beyond what Ollama's FAQ says.
  • We did not take a screenshot of the run, so the commands and answers above are the copied text.

Try it yourself

  1. Install Ollama from ollama.com for your system, then open a terminal.
  2. Run: ollama pull qwen2.5:0.5b (a small download, good for a first try).
  3. Run: ollama run qwen2.5:0.5b followed by your question in quotes, using made-up text first.
  4. Read the answer carefully, and compare it with the original before relying on it.
