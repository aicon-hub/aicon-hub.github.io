Piper: free offline text-to-speech with Hindi and Malayalam voices

By AiCoN | Published 27 October 2026 | Sources checked 27 October 2026

Piper is a free text-to-speech engine that runs on your own computer. You type or pipe in text and it writes a sound file, with no account and no web service. It is a command-line tool, so it suits people who are comfortable with a terminal. On 27 October 2026 we installed it, downloaded English, Hindi and Malayalam voices, and generated speech files from made-up sentences, once on a small Linux machine with the network switched off and once in a Google Colab notebook. This guide covers what worked, and one thing to check before you use a voice: each voice has its own licence.

Quick facts

  • What it is: Piper is a fast, local neural text-to-speech engine. Development moved to github.com/OHF-Voice/piper1-gpl, from the Open Home Foundation, and the older rhasspy/piper repository is marked archived.
  • Licence of the engine: the new repository is under GNU GPL v3. The archived repository was under the MIT licence. The README says the maintainers are looking for new maintainers.
  • Voices: the project lists voices for many languages, including Hindi (hi_IN), Malayalam (ml_IN) and Telugu (te_IN). Voices are separate downloads of about 60 MB each in our test.
  • Voices have their own licence information, separate from the engine. The Hindi voice we used (priyamvada) lists CC BY-NC-SA 4.0 for its dataset on its model card. The English voice (lessac) model card points to its dataset's own licence page. The Malayalam voice (meera) model card says "See URL" and points to a Kaggle page. We draw no conclusion about what you may do with generated audio; read each card.
  • Install: pip install piper-tts (the package's PyPI listing for version 1.8.0 says Python 3.9 or newer; we tested on 3.10), then python -m piper.download_voices followed by the voice name.
  • Cost: the engine is free to download. No payment or card was involved in our test.
  • Privacy: after the voices were downloaded, our speech runs worked with the network switched off. That is our observation on one setup, not an audit.
  • India: the voice list includes Hindi, Malayalam and Telugu voices. We found no India-specific statement in the pages we read and did not verify any region rules.

Why use it

Piper turns text into audio files on your own machine. That is handy for reading notes aloud, making audio for a study handout, or building a small project that talks. Because it is a local program, the text you give it stays on your computer in our test.

What we tested

On 27 October 2026 we used a clean Python 3.10 environment on a small Linux machine (about 1 GB of memory, 2 CPU cores, no GPU).

  • Install and generate (local): pip install piper-tts installed version 1.8.0 without errors. We downloaded three voices: en_US-lessac-medium, hi_IN-priyamvada-medium and ml_IN-meera-medium. With the network switched off, Piper wrote three sound files of 5.7, 8.1 and 4.4 seconds, in about 3.7 seconds in total.
  • Same commands in Colab: we ran the same install, download and three commands in a new Google Colab notebook. It took about 27 seconds and showed three audio players (screenshot below). That run needed the internet, as Colab does.
  • Input sentences (made up): English: "The library will be closed on 3 November for maintenance. Please return your books before 2 November." Hindi: "पुस्तकालय रखरखाव के लिए 3 नवंबर को बंद रहेगा। कृपया 2 नवंबर से पहले अपनी किताबें लौटाएं।" Malayalam: "ലൈബ്രറി അറ്റകുറ്റപ്പണികൾക്കായി നവംബർ 3 ന് അടച്ചിരിക്കും."
  • What the output shows: audio files were generated successfully. Automated transcription matched the English input and nearly matched the Hindi; the Malayalam differed. This does not establish whether a mismatch comes from the speech generation or from the transcription. Pronunciation and naturalness have not been rated, so play the files yourself before relying on them.
  • Not tested: a human listening test, the web demo, other voices, GPU use, the HTTP server, Windows and Mac, and the Telugu voices.

Try it yourself

  1. Install Python (3.9 or newer per the package's PyPI listing), then run: pip install piper-tts
  2. List voices with python -m piper.download_voices and download one, for example python -m piper.download_voices en_US-lessac-medium
  3. Make a file: python -m piper -m en_US-lessac-medium -f test.wav -- 'This is a test.'
  4. Read the voice's model card on Hugging Face for its licence information before sharing or selling audio.

Sources checked 27 October 2026. The transcription check was for our own testing and is not a quality rating.
