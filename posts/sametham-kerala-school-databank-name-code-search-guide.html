Sametham: find a Kerala school by name or code on KITE's data bank

By AiCoN | Published 7 November 2026 | Sources checked 7 November 2026

Need a school's official code, teaching levels or listed contact details? Start with Sametham, KITE's Kerala school data bank. We searched for "Aruvikkara", got four matching schools, and opened the government higher secondary school's profile. Searching its school code, 42003, also worked. This is a directory lookup, not an admission application.

Quick facts

  • Official starting point: sametham.kite.kerala.gov.in.
  • KITE describes the data bank as covering government, aided and recognised unaided schools in Kerala.
  • We checked: name search, school-code lookup and a basic-information profile.
  • No account, personal documents, OTP, card or payment was requested for these public lookups.
  • The homepage and search results label the data updated 27 June 2026. That is the provider's data date, not today's verification of every school record.
  • We did not check: admissions, phone calls, maps, staff records or current seat vacancies.

Why use it instead of asking a chatbot?

Similar school names can point to different institutions. Sametham lets you compare an official-source school code, name, local area and level before choosing a record. It is a better starting point than a phone number or school code generated without a source. Confirm important details with the school before travelling or applying.

Search by name

  1. Open the official Sametham homepage.
  2. Enter a distinctive part of the school name in Filter Search. We used Aruvikkara.
  3. Select Search and wait for the results table. A blank page appeared briefly while our results loaded.
  4. Compare the school code, name, block/local-body information and level. Do not choose a result from its name alone.
  5. Open the school-name link to read its profile. On a narrower screen, scroll the wide table sideways to see additional columns.

Already have the school code?

Enter the code in the same Filter Search box and select Search. In our check, 42003 opened the Govt. H S S Aruvikkara profile. Its Basic Information section displayed school code 42003, HSS code 1139, school type Government, level 5-12, location fields and separate section contacts. Check which code your form asks for: a school code, HSS code and UDISE code are different fields.

What not to infer from a listing

  • A listed level such as 5-12 does not tell you whether a seat is available in a particular class or stream.
  • A phone or email field does not prove the contact is answered or recently updated. Confirm directly before relying on it.
  • Infrastructure fields are not an independent inspection, safety certification or school-quality score.
  • Do not use student-strength totals as a live admission counter.

If a page is blank

Wait for the results to finish loading. In one visit, the homepage returned an empty-response error and loaded after one Reload. The current Advanced Search route stayed blank on two reads in our earlier check, so this guide uses the working basic name/code search instead. We did not verify Advanced Search filters or every district's records.

Limits of our check

We checked public desktop name and code lookups on 7 November 2026. We did not sign in, upload documents, call a school, submit an admission form, verify a map route or inspect staff/student records. No payment was requested in the lookups we ran. That says nothing about school fees or other services. A dated directory record should not replace direct confirmation for an application, journey or admission decision.

Sources: Official Sametham homepage Search endpoint Example school profile Official user manual, Checked 7 November 2026. Details can change; check the official source before you act.
