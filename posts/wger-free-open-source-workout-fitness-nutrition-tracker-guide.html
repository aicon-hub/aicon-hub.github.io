wger: free open-source workout and nutrition tracker

By AiCoN | Published 17 October 2026 | Sources checked 17 October 2026

wger is a free, open-source workout and nutrition tracker. Its README says "100% Free & Open Source" and lists apps for Android, iOS, F-Droid and Flathub.

What it is

wger (pronounced "VEH-ger") is a workout and fitness tracker. Its GitHub README calls it "a free workout and fitness manager". You can build workout routines, log your body weight and measurements, and track food with a calorie log. There are apps for Android, iOS, F-Droid and Flathub, per the README. It is not an AI tool. We included it as a free fitness tracker that is open source.

Is it free?

Yes, per the project. The README lists "100% Free & Open Source" and says the application code is under the AGPL-3.0 or later licence. The docs say the same. We saw no price or paid plan in the sources we read. The wger.de website sits behind a bot check, so we could not read its pages, and we cannot say what the hosted site offers beyond what the README says.

What you can do with it

  • Workout routines. The README says you can create flexible routines with automatic weight progression rules.
  • Body tracking. Track body weight and custom measurements. The manual says it covers weight, body fat, arm circumference, blood pressure, sleep and more, drawn as charts.
  • Nutrition. Log your calories with a food database from Open Food Facts, per the README.
  • Exercise wiki and progress photos. The README lists a built-in exercise wiki and a progress gallery for photos.
  • Connect your phone's health data. Since version 2.7 the mobile app can import from Apple Health or Health Connect, if you turn it on under Settings, and you choose which kinds of data to share, per the manual.

What to watch out for

  • Aimed at self-hosting. The GitHub description says "Self hosted". The README says you can run your own copy with Docker. The docs say they are for developers and administrators. We did not find an official page here that explains how to start as a normal user on the hosted site, because wger.de was blocked to us.
  • It is a tracker, not a coach or medical tool. It stores numbers you enter, such as weight and blood pressure. It does not give advice.
  • Not tested. We did not make an account or try the apps.

Privacy and data

  • The tool stores personal health numbers you enter, and optionally progress photos. We did not read the privacy policy of the hosted site.
  • If you run your own copy, the README says your data stays under your own control. This is the README's "full control" claim, not something we tested.
  • The phone health import is optional and you can decline each data type, per the manual.

India

  • We found no region limit in the docs. We did not check the app stores in India, and no rupee price is involved.

Yes, per its README: "100% Free & Open Source".

The README lists Android, iOS, F-Droid and Flathub.

Yes. The README says it is a Docker command away.
