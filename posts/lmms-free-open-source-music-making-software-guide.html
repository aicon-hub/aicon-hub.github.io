LMMS: free open source software to make beats and music

By AiCoN | Published 20 October 2026 | Sources checked 20 October 2026

LMMS calls itself a 100% free, open source tool for making music, with built-in synthesizers and sample support.

What it is

LMMS is a program for making music on a computer. Its website says you can create "melodies and beats", synthesize and mix sounds and arrange samples. It runs on Linux, Windows or macOS, per the site. It is a desktop program, not an AI tool and not a phone app.

Is it free?

Yes, per LMMS. The home page says "LMMS is a 100% free, open source, community-driven project", and the download page says "Downloading and using LMMS is free!". GitHub lists the licence as GPL-2.0. We saw no price and no sign-in step on the pages we read.

What the site lists

  • A Beat+Bassline Editor to arrange instrument tracks.
  • 16 built-in synthesizers, including emulations of the Roland TB-303, the Commodore 64 SID chip, the Nintendo NES and GameBoy sound chips and the Yamaha OPL2 chip.
  • An embedded ZynAddSubFx synthesizer.
  • SoundFont (SF2), Giga (GIG) and Gravis UltraSound (GUS) sample formats.
  • VST instrument support. Per the site, 64-bit VST instruments are built in, and VST effects work on Linux and Windows.

Good to know, per LMMS

  • The download page lists version 1.3.0-alpha.2 when we read it. "Alpha" means a test release. We did not check whether there is a newer stable version.
  • The download page has a note about a buggy macOS 10.13 build on macOS 10.14 or newer.
  • The site has a documentation section and a promo video, which we did not watch.

Our advice

  • It suits a beginner who wants to try making beats without paying. Expect a learning curve, as with any music software.
  • Download it only from lmms.io, and check the release name on the download page first.

Privacy and data

  • We read no privacy statement. The LMMS website loads an analytics script, so the site itself may track visits. We did not check the program and make no claim on what it collects.

India

  • No region limit appears on the pages we read. We did not test it from India. There is no price to convert.

Source code

The GitHub project LMMS/lmms is under GPL-2.0, per its GitHub page.
