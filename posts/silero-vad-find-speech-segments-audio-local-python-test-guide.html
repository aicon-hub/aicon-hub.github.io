Silero VAD: find likely speech segments in audio locally

By AiCoN | Published 28 October 2026 | Sources checked 28 October 2026

Silero VAD is an AI voice activity detector: it marks time ranges in audio that look like speech. It does not turn words into text, identify a speaker or remove noise. A programmer can use those time ranges to decide which parts to send to a transcription step. We ran it locally on a synthetic English voice clip with added silence, then on digital silence and a pure tone. It returned two speech ranges for the voice clip and none for the other two samples.

Quick facts

  • What it is: a pretrained voice activity detector maintained in the Silero VAD repository. The README lists 8,000Hz and 16,000Hz sample-rate support. We tested 16,000Hz only.
  • Licence: the project's actual LICENSE file is MIT. This is separate from the rights to any audio you process.
  • Setup: silero-vad 6.2.3 lists Python 3.8 or newer. Our test used Python 3.10, PyTorch and the bundled ONNX route on CPU.
  • Cost: free open-source package. No API key, account, card or payment was requested in our local test.
  • Privacy scope: the completed test worked with networking disabled after setup. This is an observation on our setup, not a network audit. We used synthetic audio, not anyone's private recording.
  • India: India-specific availability was not established. This was a local installation, not an India-location test.

When it helps

If you are building an audio workflow, timestamps let you locate likely speech before a separate transcription or review step. Keep the original: a detector can miss quiet speech, include noise or split an utterance. It should not be the sole basis for deleting parts of a recording. It also cannot tell you what was said or who said it.

Our synthetic test

On 28 October 2026 we used Silero VAD 6.2.3 on Linux/Python 3.10 with CPU inference and the ONNX option. We took an earlier synthetic English text-to-speech clip, resampled it to 16kHz, placed two seconds of silence before it and three seconds after it. The source clip occupied 2.00-7.65 seconds in the combined signal. We also tested five seconds of digital silence and five seconds of a 440Hz sine tone. These are controlled samples, not real conversations.

Exact code

import numpy as np
import torch
from scipy.io import wavfile
from scipy.signal import resample_poly
from math import gcd
from silero_vad import load_silero_vad, get_speech_timestamps

torch.set_num_threads(1)
rate, speech = wavfile.read("test-speech.wav")
speech = speech.astype(np.float32) / 32768
if speech.ndim > 1:
    speech = speech.mean(axis=1)
g = gcd(rate, 16000)
speech = resample_poly(speech, 16000 // g, rate // g)
# Synthetic TTS audio, followed by silence. Not a real recording.
combined = np.concatenate([np.zeros(32000), speech, np.zeros(48000)]).astype(np.float32)
tone = (0.1 * np.sin(2 * np.pi * 440 * np.arange(16000 * 5) / 16000)).astype(np.float32)
model = load_silero_vad(onnx=True)
for name, audio in [("TTS with silence", combined), ("five seconds silence", np.zeros(80000, np.float32)), ("five seconds tone", tone)]:
    result = get_speech_timestamps(torch.from_numpy(audio), model, sampling_rate=16000, return_seconds=True)
    print(name, "duration", round(len(audio)/16000, 2), "segments", result)
print("TTS inserted at", 2.0, "to", round(2+len(speech)/16000, 2))
np.save('combined.npy',combined)

test-speech.wav refers to our synthetic test input, not a file bundled with Silero VAD or a download offered here. For reuse, choose a 16-bit PCM WAV you own; this example assumes that sample format. Do not assume its normalisation handles every audio format.

Copied output

TTS with silence duration 10.65 segments [{'start': 2.0, 'end': 5.1}, {'start': 5.2, 'end': 7.5}]
five seconds silence duration 5.0 segments []
five seconds tone duration 5.0 segments []
TTS inserted at 2.0 to 7.65

The detector split the synthetic voice into two spans, 2.0-5.1 and 5.2-7.5 seconds, rather than matching the entire inserted clip. Silence and tone returned empty lists in this test. That does not prove it rejects music or real-world background noise, or that all speech will be retained. The identical script produced the same output with networking disabled after setup.

Try the route

pip install "silero-vad[onnx-cpu]==6.2.3" scipy

Use an environment with compatible PyTorch and NumPy dependencies, and a short audio file you own. Start with a copy, inspect the returned ranges and listen to the corresponding audio before making edits. The script saves a NumPy array of the combined signal for inspection; it does not edit the original WAV.

Limits

  • One synthetic English voice clip, digital silence and a pure tone. No human speech, noisy rooms, music, overlapping speakers, accents, Hindi or Malayalam were tested.
  • No accuracy, latency or false-positive benchmark. The returned spans are this detector's output, not verified word boundaries.
  • We did not test transcription, speaker identification, automatic deletion, mobile deployment, GPU inference, streaming or the 8kHz route.
  • No voice audio is published. The code/output are selectable text, not a reconstructed terminal screenshot.
