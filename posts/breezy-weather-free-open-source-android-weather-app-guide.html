Breezy Weather: a free, open-source weather app for Android

By AiCoN | Published 17 October 2026 | Sources checked 17 October 2026

Breezy Weather is a free, open-source weather app for Android. Its README says it shows forecasts, air quality, pollen and alerts from more than 50 sources, and its privacy policy says it collects no personal data.

What it is

Breezy Weather is a weather app for Android phones. Its README calls it "a feature-rich free and open source Material 3 Expressive weather app" that shows forecasts, observations, air quality, pollen and alerts from more than 50 weather sources. It is not an AI tool. We included it as a free weather app for Android.

Is it free?

Yes, per its README: the features list says "Free and Open Source", and the project license is LGPL-3.0 on GitHub. You download it from the project's GitHub releases page, from F-Droid or from other sources listed in its install guide. It is not on the Google Play Store; the README lists that as something the project will not do. We saw no price. The project asks for donations to Open-Meteo, a weather data source, not to itself.

What it shows

  • Daily and hourly forecasts up to 16 days, per the README.
  • Precipitation in the next hour, severe weather alerts, air quality, pollen, UV, wind, humidity and more.
  • 24-hour charts, home screen widgets, a live wallpaper, dark mode and custom icon packs.
  • Screen reader support: the README says most things should work.

Does it work in India?

Likely yes. The project's sources page lists the India Meteorological Department (IMD) as a source for India, with forecasts up to 10 days, hourly and daily. It says IMD has no air quality, alerts or current-observation data in the app. It also lists worldwide sources such as Open-Meteo. We did not install the app or check how accurate the forecasts are for any Indian city.

How to get it

  1. Open the project's install guide and pick a source: GitHub releases, an F-Droid repository, or Izzy's repository.
  2. For GitHub, the guide says to download the file named like breezy-weather-vX.Y.Z_standard.apk and install it.
  3. Add a location by hand or allow the app to use your location.

The latest release we saw on GitHub was v6.2.2. The README shows an "API 21+" badge, which is Android's version number for Android 5.0 and above.

What to watch out for

  • Installing from outside the Play Store. You may have to allow installs from your browser or file manager. Only download from the project's own links.
  • Two versions. The install guide says the standard version has all sources, while the F-Droid default repository offers a version with only free-network sources.
  • Weather data comes from other services. Some sources need an API key; the sources page says the app comes with a pre-bundled key for some, and a few are rate-limited. A key can be set in the app.
  • Refresh rate. The README says options to refresh more often than every 30 minutes will not be added.

Privacy and data

  • The privacy policy says: "Breezy Weather doesn't collect any personal data."
  • Location is optional. The policy says it can use your approximate or precise location to find weather for your position, and that data goes to the weather source you pick. You can deny the permission and choose a city by hand.
  • The README says it has no trackers and no automatic crash reporters.
  • If you turn on update checks, the app connects to GitHub at most every 24 hours.

Frequently asked questions

Is Breezy Weather free?

Yes, per its README it is free and open source (LGPL-3.0).

Is it on the Play Store?

No. The README says the project will not publish there. See the install guide for other sources.

Does it collect my data?

Its privacy policy says it collects no personal data. Your location goes to the weather source if you allow it.

Is there an iPhone version?

We saw only Android install options.
