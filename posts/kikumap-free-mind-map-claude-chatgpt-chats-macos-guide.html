KIKUmap: a free mind map for your Claude and ChatGPT chats (Mac only)

By Muhammed Salman | Published 10 November 2026 | Sources checked 10 November 2026

KIKUmap is a free, open-source app for the Mac menu bar. It watches your pinned Claude and ChatGPT desktop chats and shows which are still running, which have finished and which are waiting for you. Open it, and those chats become a mind map you arrange yourself. It is macOS only: there is no Windows or Linux version.

Quick facts

  • What it is: a menu-bar app that tracks pinned chats in the Claude and ChatGPT desktop apps, plus Claude Code sessions, and lays them out as a mind map. Version 1.1.0, released 8 November 2026.
  • Cost: free and open source under the MIT licence. The download is about 5 MB.
  • Works on: macOS 13 or later, on Apple silicon and Intel. The desktop widget needs macOS 14 or later. No Windows or Linux version exists, so Linux users (Fedora included) and Windows users cannot use it.
  • Privacy: the developer says everything stays on your Mac, with no network requests except optional usage lookups that are off by default.
  • Independent: it is not made by Anthropic or OpenAI. It reads the Claude app through macOS Accessibility and ChatGPT through files its desktop app keeps on the Mac, so parts can break when those apps update.
  • Checked by AiCoN: we read the GitHub repository and the official site on 10 November 2026. We could not install or run KIKUmap: it needs a Mac, and we do not have one.

What it does

  • Menu-bar status: a small flower spins while a pinned chat runs. A red badge counts finished chats you have not read, with an exclamation mark when one needs your approval or answer. An optional sound or spoken alert names the finished chat.
  • Chats as a map: pinned Claude and ChatGPT Codex chats and Claude Code sessions line up in a column. Drag them onto your own topics, MindNode-style, with colours, shapes, a timeline view, keyboard shortcuts and PDF export.
  • Desktop widget (macOS 14 or later): the same status at a glance, with time worked and Claude and ChatGPT plan usage.
  • Coverage: the Claude desktop app, Claude Code (Terminal, VS Code and the app's Code mode) and Codex chats in the ChatGPT desktop app. Ordinary ChatGPT chats are kept online, not on your Mac, so support for them is limited; unpinned chats and anything on another computer or server do not show.

How to install

  1. Download Kikumap.dmg from the project's GitHub releases page and drag KIKUmap to Applications.
  2. The app is not notarized, so on first launch macOS says it cannot be checked. Click Done, then open System Settings, go to Privacy and Security, and choose Open Anyway. Do this only for the DMG from the official repository.
  3. Grant Accessibility when macOS asks; the app explains each permission before the system prompt. Full Disk Access is optional and only reads Claude's notifications.
  4. You can also build it from source with the Install.command script in the repository.

Privacy, in short

  • Its data lives in ~/Library/Application Support/ClaudeConsole/ on your Mac.
  • No network requests, except the optional usage lookups to Anthropic and OpenAI, which are off by default. The developer notes neither company has approved such lookups, so they could stop working.
  • Export and import pass through the clipboard, marked so clipboard-history tools skip them, and your clipboard is put back after each step.

Limits and things to know

  • AiCoN did not test KIKUmap. Everything above is from the developer's README and site, not our measurement.
  • Because it reads other apps' windows and files, an update to Claude or ChatGPT can break parts of it until KIKUmap catches up.
  • If you are on Linux or Windows, this one is not for you. There is no alternative build.
