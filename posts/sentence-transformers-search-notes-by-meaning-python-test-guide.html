Sentence Transformers: search your notes by meaning with Python

By AiCoN | Published 27 October 2026 | Sources checked 27 October 2026

Sentence Transformers is a free Python library that turns sentences into lists of numbers, so you can compare them by meaning instead of by exact words. That lets a short script find the note that answers a question even when the note uses different words. It needs a little Python, so it suits students and hobbyists who can run a script. On 27 October 2026 we ran it on eight made-up student notes and four questions. Three matches were clear and one was weak, and this guide shows all four.

Quick facts

  • What it is: an open-source Python library, originally created by the UKP Lab at TU Darmstadt and now maintained by Hugging Face, with documentation at sbert.net.
  • Licence: the library's GitHub repository lists the Apache License 2.0. The model we used, all-MiniLM-L6-v2, lists apache-2.0 on its Hugging Face model card. Other models have their own licences.
  • Python: the PyPI metadata for version 6.2.0 lists Python 3.10 or newer.
  • Language: the model card for all-MiniLM-L6-v2 lists English. We did not test Hindi, Malayalam or any other language.
  • Cost: the library is free to download. No payment or card was involved in our test. Other models and hosted services were not checked.
  • Privacy: the first run downloaded the model (about 90 MB), so it needs internet once. After that, our run worked with the network switched off. That is one observation on our setup, not an audit.
  • India: we did not find an India-specific statement in the sources we read, and did not check for one further.

Why use it

Exact-keyword search can miss a note that uses different words. This library compares meaning, so a question like "when do I need to settle my accommodation charges?" can point to a note that says "hostel fee". You keep your own notes in a plain list or file and the search runs on your own computer, so no note needs to be uploaded to a chat service. The trade-off is that you run Python code yourself.

What we tested

We used a clean Python 3.10 environment on a small Linux machine (about 1 GB of memory, 2 CPU cores, no GPU) with sentence-transformers 6.2.0 and the all-MiniLM-L6-v2 model. The notes below are made up. The four questions were worded differently from the notes they matched. We ran the same code once more in a Google Colab notebook, which gave the same results; we are not offering that notebook as a download.

The code we ran

from sentence_transformers import SentenceTransformer, util

notes = [
    "Pay the hostel fee at the accounts office before 5 November.",
    "Chemistry lab report is due next Friday, include the titration table.",
    "Bus to the college leaves at 7:40 from the main gate.",
    "Library closes for maintenance on 3 November, return books early.",
    "Ask Priya for the data structures lecture notes from Monday.",
    "Scholarship form needs a bank passbook copy and income certificate.",
    "Practice sorting algorithms: bubble sort, merge sort, quicksort.",
    "Mess menu changes from Monday, dinner is now at 8 PM.",
]
queries = [
    "when do I need to settle my accommodation charges?",
    "which documents do I need for financial aid?",
    "how do I get to campus in the morning?",
    "what should I revise for programming exam?",
]

model = SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2")
note_vectors = model.encode(notes, convert_to_tensor=True)
for q in queries:
    scores = util.cos_sim(model.encode(q, convert_to_tensor=True), note_vectors)[0]
    best = int(scores.argmax())
    print(f"Q: {q}\n   top note: {notes[best]}  (cosine {float(scores[best]):.2f})")

The output we got

Q: when do I need to settle my accommodation charges?
   top note: Pay the hostel fee at the accounts office before 5 November.  (cosine 0.54)
Q: which documents do I need for financial aid?
   top note: Scholarship form needs a bank passbook copy and income certificate.  (cosine 0.61)
Q: how do I get to campus in the morning?
   top note: Bus to the college leaves at 7:40 from the main gate.  (cosine 0.52)
Q: what should I revise for programming exam?
   top note: Practice sorting algorithms: bubble sort, merge sort, quicksort.  (cosine 0.27)

Reading the results: for the hostel fee, the financial aid and the bus questions, the top note was the one we would pick by hand. The fourth question, about what to revise for a programming exam, returned the sorting-algorithms note with a cosine score of 0.27. That note is a reasonable answer, but "Ask Priya for the data structures lecture notes" could also fit. A cosine score is a similarity number between two texts. It is not a confidence level, and we did not measure accuracy. Treat the top result as a suggestion and read the next few as well.

Limits of our test

  • Eight short notes and four questions. We did not test large note collections, speed on large data, PDFs or handwriting.
  • English only, with one model. We did not test other models, other languages, or vector databases.
  • We did not take a screenshot of the run, so the code and output above are the copied text of what we ran.

Try it yourself

  1. Install Python 3.10 or newer, then run: pip install sentence-transformers
  2. Save the code above as a file, replace the notes with your own text, and run it. The first run downloads the model, so stay online for it.
  3. Read the model card at huggingface.co/sentence-transformers/all-MiniLM-L6-v2 for its licence and language before using it for anything beyond practice.
